# Program Arcade Games With Python and Pygame — Learning Repository

This repository chronicles my hands‑on progress through *Program Arcade Games With Python and Pygame* by Dr. Paul Vincent Craven. Each exercise is rewritten using modern Python practices to create clear, educational examples that reinforce programming fundamentals through practical, interactive projects.

Because the book’s original code reflects older conventions, every lab and chapter here is updated with contemporary techniques—cleaner structure, improved readability, type hints, modular design, and consistent formatting. This project serves as both a personal study log and a helpful resource for anyone learning Python through game development.

---

## 📚 What’s Inside

- Chapter‑based Python exercises
- Modernized versions of textbook labs
- Pygame projects rewritten with clean, updated code
- Practical demonstrations of loops, functions, classes, graphics, and game logic
- Continuous progress tracked through Git
- Educational examples designed for long‑term learning
